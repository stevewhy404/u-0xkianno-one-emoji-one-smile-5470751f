One emoji, and nothing else: 🥹 — the face holding back tears, the
single warmest emoji for a stranger. It reads at a glance as someone
genuinely moved: not a default smiley, not a joke, not a flirt — just
a stranger's kindness landing exactly where it should.

Built for [make.fun](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f).

## How it works

`main.py` (stdlib only) writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt`
and nowhere else. The entry is exactly one character, well inside the
1–8 character gate.
